## Specification
### Mappings  
- **ALIE**: Represents a user-defined meaning.  
- **A11Y**: Represents accessibility-related meaning.  
- **'-'**: Refers to the negation rule.  
- **US/01**: Linked to 0321, governed by negation ('-').  
- **I**: Phonetic symbol.  
- **AM**: Phonetic connector.  
- **1**: Numeric token.  
- **RU2**: Represents a query/state label.  

### Configuration  
- **`MAX_LEN`**: Sets max context size.  
- **Units**: Preferred as tokens.  
- **Scope**: Covers input, output, and history.
